# ナンバーサム・ピクロス (NumSum Picross)

足し算パズル「ナンバーサム」の計算ロジックと、お絵かきパズル「ピクロス」の達成感を融合させた新感覚パズルゲームです。

## 技術選定とレスポンス最適化の理由

構想案の初期プロトタイプを、**依存関係ゼロのモダンWebアプリケーション（HTML5 + モダンCSS3 + Vanilla JavaScript）** として実装しています。

- **ゼロレイテンシ入力:** 仮想DOMの差分計算やバンドラのオーバーヘッドを持たず、`pointerdown` イベントで即座に盤面を更新するため、タップ／クリック直後の応答が最速です。
- **ドラッグ連続塗りつぶし:** マウス・タッチの両方で指を滑らせて複数マスを一気に選択／解除できます。
- **即時起動:** ビルドやサーバー起動なしで `index.html` をブラウザで開くだけで動作します（デスクトップ・スマートフォン両対応）。
- **軽量な触覚フィードバック:** Web Audio API による合成効果音と、CSS Compositor（`scale` / `opacity`）中心のアニメーションを採用しています。

## ルールと操作方法

1. **目標合計値に合わせる:** 行（左端）と列（上端）に目標となる合計値が書かれています。
2. **マスを塗りつぶす:** 選択したマスの数字だけが合計に加算されます。
   - **左クリック / タップ:** マスの選択・解除（そのままドラッグで連続入力可能）
   - **右クリック / ✖️メモモード:** 除外したいマスに `×` 印を付ける（合計値には影響しません）
   - **キーボード操作:** `矢印キー` または `WASD` でマス移動、`Space` / `Enter` で塗りつぶし、`X` キーで `×` 印メモ
   - **ツールバー:** モード切替、リセット、音声ON/OFF、ステージ切替（❤️ ハート / ⭐ スター / 😊 スマイル）
3. **クリア:** すべての行と列の合計値が目標値と一致する（ヘッダーが緑色に点灯する）と、隠れていたドット絵が浮かび上がります。

## ステージ1（ハート）の数値検証・修正について

原案の $5 \times 5$ ハート型ステージでは、`targetRows` の総和が `6 + 23 + 11 + 5 + 0 = 45` である一方、`targetCols` が `[4, 13, 14, 13, 2]`（総和 `46`）となっていました。
`gridNumbers` の第2列と `answerMap` を照合すると `3 + 7 + 2 = 12` となるため、本実装では `deriveTargets(gridNumbers, answerMap)` によりターゲット値を自動算出し、第2列の目標値を `12`（総和 `45`）に修正して詰みが発生しないよう保証しています。

## ファイル構成

- `index.html` — セマンティックHTML5によるゲーム画面構造
- `styles.css` — コンテナクエリ・`dvh`・ライト/ダークモード対応のレスポンシブスタイル
- `app.js` — ゲームロジック（`deriveTargets`, `calculateCurrentSums`, `checkIsCleared`）、3ステージ定義、UI/ドラッグ/キーボード/Web Audio制御
- `test.js` — Node.js によるロジック・ステージ整合性の自動テスト
- `AGENTS.md` — AIエージェント向け開発・保守ガイドライン

## 起動・テスト方法

- **プレイする:** ブラウザで `index.html` を直接開いてください。
- **テストを実行する:**
  ```powershell
  node test.js
  ```
