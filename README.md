# ナンバーサム・ピクロス (NumSum Picross)

足し算パズル「ナンバーサム」の計算ロジックと、お絵かきパズル「ピクロス」の達成感を融合させた新感覚パズルゲームです。

## 特徴

- **3つの難易度・全38問のドット絵ステージ:**
  - **かんたん (`5 × 5`)** — 全12問 / サクッと遊べる
  - **ふつう (`8 × 8`)** — 全13問 / ちょっと手応え
  - **むずかしい (`10 × 10`)** — 全13問 / じっくり挑戦
- **段階解放システム（プログレッシブアンロック）:**
  - 各難易度とも最初は第1問からスタートし、1問クリアするごとに次の問題が順番に解放されます（進捗はブラウザの `localStorage` に自動保存されます）。
- **全問ユニーク解保証:**
  - 38問すべてについて、行・列の合計値だけで一意に解ける盤面データ（`1〜9`）を生成・検証しています。
- **遊び方・ルールモーダル:**
  - トップ画面・ステージ一覧・プレイ画面からいつでも「遊び方・ルール」を確認できます。
- **ゼロレイテンシ入力 & 快適な補助機能:**
  - `pointerdown` 即時反映＋ドラッグ連続塗りつぶし（マウス／タッチ両対応）
  - 右クリックまたは「✖️ メモ中」モードによる `×` 印メモ
  - `💡 ヒント`（誤選択の修正または正解マス1つを案内）、`🔄 リセット`、Web Audio API 合成効果音

## 操作方法

1. **難易度を選択**し、解放されている問題からスタートします。
2. **塗りつぶし:** 左クリック／タップ（ドラッグで連続選択）。選んだマスの数字だけが行と列の合計に加算されます。
3. **色のヒント:**
   - 見出しが **緑色** … 目標値とピッタリ一致！
   - 見出しが **赤色** … 目標値をオーバー！
4. **× 印メモ:** 右クリック、またはツールバーの「✖️ メモ中」で除外メモをつけられます（合計値には影響しません）。
5. **キーボード操作:** 矢印キー / `WASD` で移動、`Space` / `Enter` で塗りつぶし、`X` で `×` 印。

## ステージ1（ハート）の数値検証・修正について

原案の $5 \times 5$ ハート型ステージでは、`targetRows` の総和が `6 + 23 + 11 + 5 + 0 = 45` である一方、`targetCols` が `[4, 13, 14, 13, 2]`（総和 `46`）となっていました。
`gridNumbers` の第2列と `answerMap` を照合すると `3 + 7 + 2 = 12` となるため、`deriveTargets(gridNumbers, answerMap)` によりターゲット値を自動算出し、第2列を `12`（総和 `45`）に修正しています。

## ファイル構成

- `index.html` — 難易度選択・ステージ一覧・ゲーム画面・ルールモーダル（`<dialog>`）のマークアップ
- `styles.css` — ダークネイビー基調のレスポンシブスタイル（コンテナクエリ `cqi`、`dvh`、`prefers-reduced-motion` 対応）
- `stages.js` — 難易度定義（`DIFFICULTIES`）および全38問の検証済みステージデータ（`STAGES_BY_DIFFICULTY`）
- `app.js` — 計算ロジック、段階解放管理（`applyStageClear`）、ヒント探索（`findHintCell`）、UI／ドラッグ／キーボード／Web Audio 制御
- `test.js` — 全38問の整合性・段階解放ロジック・ヒント機能を検証する Node.js テスト
- `AGENTS.md` — AIエージェント向け開発・保守ガイドライン

## 起動・テスト方法

- **プレイする:** ブラウザで `index.html` を直接開いてください（`file:///` でも動作します）。
- **テストを実行する:**
  ```powershell
  node test.js
  ```
